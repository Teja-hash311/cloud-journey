My goal: securing a cloud engineering internship in summer 2027.

## My AI Learning Rules

1. Ask AI to explain before it writes code: Always make the AI break down the logic before giving you the syntax.

2. Never keep code I cannot explain: If you can't walk line-by-line and tell someone else what it does, delete it or study it until you can.

3. Run it and break it on purpose: Don't just make it work once; tweak parameters to see what error messages it throws so you know how to debug it later.

4. Ask for a quiz after each topic: Test your active recall by having the AI quiz you before moving on.

5. Keep a list of things it got wrong: Track your mistakes and areas where the AI made errors to sharpen your own troubleshooting skills.
